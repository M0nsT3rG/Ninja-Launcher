# Code review, 2026-10-25 (commit cefd982)

An independent reviewer agent did this review. It was given only the code, not the author's reasoning. Codex CLI was unavailable because it had hit its usage limit.

| # | Severity | Finding | Resolution |
| --- | --- | --- | --- |
| 1 | High | Loader profiles put the vanilla jar on the classpath, so NeoForge/Forge 1.17+ failed with a module conflict | The client jar now goes in `versions/<profile>/<profile>.jar` (b1a751a). Booted NeoForge and Forge to confirm |
| 2 | Med-high | A failed world backup left a truncated zip that looked valid | The zip is written to `.tmp` first, `session.lock` is skipped, and backups are refused while the instance is running |
| 3 | Medium | Shared legacy natives were overwritten while another instance had them loaded | Existing natives are no longer overwritten |
| 4 | Medium | Linux ARM got the x64 Java runtime | ARM now uses platform keys that Mojang doesn't publish, so the launcher falls back to the system Java |
| 5 | Medium | `async void` handlers could crash the app; concurrent settings saves were lost | Handlers are wrapped in `RunAsync`, global exception handlers were added, and settings updates are serialised (`SettingsHolder.UpdateAsync`) |
| 6 | Medium | Retrying a Play job bypassed the already-running guard | The guard moved inside the job body |
| 7 | Medium | Modrinth installs piled up duplicate mod versions | A per-instance project→file ledger (`.ninja/modrinth.json`) replaces old copies; release builds are preferred; dependency `version_id` is honoured |
| 8 | Med-low | Background jobs saved a stale instance snapshot | `InstanceService.SetLaunchVersionAsync` re-reads the instance and patches only the launch fields |
| 9 | Low-med | Overlapping loader-version requests mixed their lists | Older requests are dropped by a counter; Create checks the Forge version prefix |
| 10 | Low-med | Delete, repair and restore ran while the game was open | `EnsureNotRunning` guards these actions |
| 11 | Low | A legacy parent with a modern child lost its classpath or game args | Legacy and modern args are combined |
| 12 | Low | Runtime symlinks could be chained during a reinstall | Incomplete runtimes are rebuilt in a fresh folder |
| 13 | Low | `SanitizeName` could cut off file extensions | The extension is kept |
| 14 | Low | Crash stack traces were dropped from the in-app log | `Throwable` CDATA is parsed as an error line |
| 15 | Low | Timeouts were reported as "Cancelled" | Timeouts are now `TimeoutException`, retried and reported as failures |
| 16 | Low | Concurrent token refreshes raced on one temp file | Temp file names are unique, and refreshes for an account run one at a time |
